Purpose

This plan aims to replace the simplistic and low-value bottom-up "Min, Max, Average" statistical calculations currently replicated across the codebase (e.g., Min Attention, Avg Attention, Min Line Width) with highly strategic, domain-specific "high-value slices" that offer actionable insights to architects and managers. In addition, it outlines specialized architectural components to calculate and render these rich insights in an interactive TUI.

Problem

The current implementation of Gitic's TUI uses a basic physical directory aggregation in TuiNode.AggregateStats that computes the minimum, maximum, and average values for Lines of Code and Line Widths. Replicating this "Min, Max, Avg" pattern to other reports (like Areas, Temporal Coupling, and Lead Times) yields minimal practical value:

  • Min metrics are usually noise: The minimum attention score or rework rate in any directory is almost always 0. Knowing that the fastest PR took 1 minute is statistically meaningless.
  • Avg metrics are diluted: Averaging risk metrics across hundreds of tiny, stable, untouched files completely washes out extreme hotspots, leading to a false sense of security.
  • Max metrics lack systemic context: Knowing the maximum attention score points to a single file, but doesn't tell you if the entire subsystem is experiencing structural decay.

Solution

Implement a modular, multi-perspective interactive TUI dashboard. Each report slice is equipped with its own dedicated mathematical formulas and high-value metrics, fully decoupled from simple directory hierarchies. We will build a unified set of supporting core components that process these analytics, render clean visual sparklines in console-safe ASCII, and allow users to filter, search, and drill down interactively.

Notes

Percentile Calculation Formula (Linear Interpolation)

To calculate the P-th percentile (e.g., P90) of a sorted array of N values (0-indexed):

double idx = (percentile / 100.0) * (N - 1);
int low = (int)Math.Floor(idx);
int high = (int)Math.Ceiling(idx);
if (low == high) return sorted[low];
return sorted[low] + (idx - low) * (sorted[high] - sorted[low]);

Encapsulation Boundary Check

A temporal coupling pair involving FileA and FileB is "cross-boundary" if:

string areaA = GetAreaOfPath(fileA);
string areaB = GetAreaOfPath(fileB);
bool crosses = !string.Equals(areaA, areaB, StringComparison.OrdinalIgnoreCase);
